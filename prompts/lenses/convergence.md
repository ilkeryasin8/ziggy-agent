**Convergence** — the code against PLAN and the user's decisions, one finding per gap. Read `## Goal & acceptance`,
the `## Plan` and `## Verification` task lists, `## Decisions (user)` and every earlier `## Review (…)` section.
An AC or task without code is `missing`; half-done is `partial`; code against an AC, a user decision or the project
doc is `contradicts`; behaviour the ticket did not ask for is `unrequested`. A `[x]` task is a claim, not evidence:
find the code. A `[regression]` task needs failing-before output recorded in PLAN and a test that passes now.
